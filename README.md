Bem-vindo(a) ao repositório do meu portfólio! Este projeto foi desenvolvido para apresentar minha trajetória, formação e projetos na área de Tecnologia.

## 🚀 Sobre o Projeto

Este portfólio foi construído com foco em organização e responsividade. A interface possui uma paleta de cores em tons terrosos, além de efeitos de vidro (Glassmorphism) e animações suaves no fundo.

### 🌟 Principais Seções:
- **Apresentação:** Introdução inicial, informações de contato rápido e atalho para o currículo.
- **Sobre Mim:** Detalhes sobre minha trajetória, destacando experiências com liderança e formação em tecnologia.
- **Projetos:** Link em destaque para o meu GitHub, com acesso rápido aos meus códigos.
- **Contato:** Informações para networking, telefone e e-mail.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web nativas:

- **HTML5:** Estruturação da página de forma semântica.
- **CSS3:** 
  - Layouts utilizando CSS Grid e Flexbox.
  - Estilos de transparência e desfoque (`backdrop-filter`).
  - Animações CSS e design totalmente responsivo.
- **JavaScript:**
  - Animações de entrada ao rolar a página (`Intersection Observer API`).
  - Funcionalidade para copiar e-mail e telefone (`Clipboard API`).
  - Navegação do menu mobile e das abas de habilidades.

## ⚙️ Como executar localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/deborabasilio/portfolio.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd portfolio
   ```
3. Abra o arquivo `index.html` em qualquer navegador web.
